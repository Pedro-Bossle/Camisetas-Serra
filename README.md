# Pedidos – Camisetas e Pins

Página estática para controlar pedidos, pagamentos e entregas.

## Publicar no GitHub Pages
1. Crie um repositório e suba **só o `index.html`** (não suba o `dados-planilha.json`: ele tem nomes e WhatsApp).
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `root` → Save.
3. Abra `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.

## Primeiro uso
💾 Dados → Importar .json → escolha `dados-planilha.json`.

## Observações
- Os dados ficam salvos no navegador (localStorage) de cada aparelho.
- Para usar em outro aparelho: 💾 Dados → Baixar backup, e importe lá.
